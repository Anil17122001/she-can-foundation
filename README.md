# She Can Foundation Website

A responsive and modern NGO website built using HTML, CSS, and JavaScript.

## 🌟 About the Project

She Can Foundation is a non-governmental organization (NGO) dedicated to empowering individuals through education, skill development, awareness programs, and community initiatives.

This project was created as a simple and user-friendly single-page website showcasing the mission, vision, and activities of the organization.

## 🚀 Features

- Responsive Design (Mobile, Tablet, Desktop)
- Modern User Interface
- Dark Mode Toggle
- Smooth Scrolling Navigation
- Image Gallery Section
- Interactive Buttons
- Scroll Animations
- Professional Footer with Contact Information
- Clean and Organized Code Structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Purpose

The goal of this project is to create an attractive and accessible website for an NGO that highlights its mission and encourages community engagement.
